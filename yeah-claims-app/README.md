# Yeah Claims Android app

Initial native Android app prototype built with Kotlin and Jetpack Compose.

## Build
GitHub Actions builds a debug APK on pushes to the `yeah-claims-app` branch or via manual workflow dispatch.

## Important prototype limitations
- The enquiry form is a UI prototype only. It does not transmit or persist personal information.
- Do not publish this build or collect real customer data until an approved secure backend, privacy notice, retention/deletion process, partner-sharing permissions and applicable South African regulatory requirements have been reviewed and implemented.
- Partner sharing consent is presented separately and is optional in the prototype.
- Replace the placeholder copy and brand styling with approved Yeah Claims website assets and wording before release.
